## 📌 About The Project

This project is a practical backend development initiative adapted from a **Turkcell Future Writers (Geleceği Yazanlar) Bootcamp** curriculum and refined with AI-driven insights to accelerate my growth as a backend engineer.

The core objective is to advance beyond standard Java/Spring Boot fundamentals and transform theoretical system design knowledge into hands-on, production-grade implementation.

### 🎯 Purpose & Methodology

* **Deep Structural Understanding:** Building the codebase from scratch without blind copy-pasting—evaluating and rationalizing every architectural decision (*"Why this design pattern?"*).
* **Interview-Ready Practice:** Bridging the gap between theory and real-world execution. The goal is to move from "I read about it" to *"I built it, broke it, and fixed it."*
* **Structured Architectural Progress:** Executing across 17 targeted phases, covering everything from core domain logic and database optimization to security layers, messaging, and test automation.

> **Note:** This repository serves as a live document of engineering decisions, system design trade-offs, and practical backend implementation. You can find the AI-generated 17-phase roadmap and detailed breakdown under the [`md-infos/`](./md-infos) directory.
